# Night Wanderer

An adventure 3D game with survival and horror elements, featuring a 3rd person view in the low-poly style. (If you know Dredge, then you already understand the basic concept).

## Game Status

Under development

## Game idea

This is a story-driven game where the player travels to another planet in a space mining ship with a mission to retrieve some data and leave the planet.

## Core Mechanics

- Upgrade your ship.
- Create new items.
- Manage your inventory however you want.
- Obtain resources through a visual mini-game.
- Explore destroyed ships to obtain blueprints and upgrades through a text-based mini-game.

## Features

- Night gameplay
- Thick fog
- Flexible inventory
- Pleasant resource collection mechanics
